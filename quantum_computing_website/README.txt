QUANTUM COMPUTING COURSE SITE - how to get a working link (GitHub Pages)
=====================================================================
1. In your GitHub repo (e.g. Data-Science or a new one), create a folder, e.g.  Quantum-Computing/
2. Upload everything from this zip EXCEPT "editable_source" (optional):
      index.html
      pdfs/   (Study-Notes, Slides, Worksheet PDFs)
3. Repo > Settings > Pages > Deploy from branch (main, / root) > Save.
4. Your link will look like:
   https://bala-durga-krishnaveni.github.io/<repo-name>/Quantum-Computing/
   (same pattern as https://bala-durga-krishnaveni.github.io/Data-Science/Data-Science-site-update/)

Notes
- Study notes, slides (one merged PDF per unit) and worksheets are now PDFs in /pdfs, like the Data Science site.
- Syllabus still points to your Google Doc. To match the other site, export it as PDF,
  name it Syllabus.pdf, put it in /pdfs and change the link to  pdfs/Syllabus.pdf
- editable_source/ holds your original .pptx and .docx files for future edits.
